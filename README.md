# Xanadu

Versión final deployable en GitHub Pages.

## Qué incluye
- uso offline una vez cargada
- base local en IndexedDB
- exportar / importar JSON
- idioma por defecto: Español
- guardián por defecto: se completa con el último cargado
- Joyitas con icono 💎
- A descubrir con icono 🧭
- Va y vuelve con persona prestada + mini historial persistente
- cámara en celular y selector de archivo en desktop

## Cómo publicar en GitHub Pages
1. Subí `index.html`, `sw.js`, `manifest.json` al repo.
2. Repo público, o privado si tu plan soporta Pages.
3. GitHub: Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main` y carpeta `/(root)`.
6. Save.

## Cómo mover el JSON del celular a la PC
1. En el celular: Exportar.
2. Guardar el archivo en Descargas / Archivos.
3. Enviarlo por cable, Drive, mail o Telegram a la PC.
4. En la PC: Importar.

## Qué no hace todavía
- sincronización automática entre dispositivos
- drag & drop
- filtro específico por guardián
